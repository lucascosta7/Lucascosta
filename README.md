# 👨‍💻 Lucas Costa

**`Analista de  Dados`**

Analista de Dados em formação, com experiência acadêmica e prática em desenvolvimento
de sistemas, manipulação de dados e automação de processos. Atuante em projetos
utilizando Python (Pandas, PySpark) e bancos de dados relacionais (MySQL e SQL Server),
com foco em consultas otimizadas, ETL e análise de dados. Possui conhecimentos em lógica
de programação, boas práticas de versionamento com Git e princípios de organização de
código para garantir qualidade e manutenibilidade. Proativo na busca por soluções
inovadoras, com perfil analítico e dedicação ao aprendizado contínuo, sempre voltado para
entregar valor e contribuir em ambientes colaborativos.
